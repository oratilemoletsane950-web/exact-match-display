# Obsidian Labs

Official website for Obsidian Labs.

## Development

Requires Node.js 22 and npm.

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Technology

- TanStack Start
- React
- TypeScript
- Tailwind CSS

## Deployment

The project includes Netlify configuration in `netlify.toml` and supports server-side rendering through Netlify functions.
